# 用户验收步骤 · 08 P1 Demo

**预置：** 已配置合法 LLM、有网、档案随意。

1. 首页点小暖，发送 `今天有点累`。应收到一段安慰式中文回复（不是「稍后再试」）。
2. 同一会话发送 `孕吐吃什么`。回复下方若有来源，标题须能在假知识 JSON 中找到。
3. 飞行模式发送 `出血了怎么办`。仍立刻出现就医固定文案（证明安全节点不依赖模型）。
4. 有网发送 `出血了怎么办`。结果须与步骤 3 **同一段固定文案**，不得变成模型长文。
5. 点林医生：仍不可用（01），不得出现林医生模型回复。
6. 开发打开日志：上述步骤 1 对应 **1 次** chat/completions；步骤 4 对应 **0 次**。
