# Specify · 18 可观测性与 SLO

**P2 埋点，P3 看板。** 源 v2 §10。App 内为主。

## 前端

### AC-18-F01 不向用户暴露内部错误
任何未捕获错误展示 `出了点问题`，无堆栈。

## 后端 / 埋点

### AC-18-B01 指标（本地计数，可后续上报）

必须能读出（dev 页或 log）：

| 名 | 定义 |
|---|---|
| `chat_success_rate` | 7 日成功回复 / 尝试次数 |
| `llm_timeout_count` | 超时次数 |
| `safety_block_count` | 拦截次数 |
| `token_sum_today` | 来自 13 |

### AC-18-B02 SLO（验收口径，P2 真机抽样 n≥20）

- 对话成功路径 P95 **≤ 8s**（含 LLM）
- 安全拦截 P95 ≤ 300ms

可用性 99.5% 为运营目标，P2 不在单元测试强断言。

### AC-18-B03 无网
主页仍可用（01）；聊天非红旗失败文案 `稍后再试`。
