# Specify · 01 主页与导航

**范围**：登录后的信息架构与主页首屏。P1 无账号体系时，**冷启动即进入主页**（单机档案）。  
**P1 隐私入口**：16 的同意 / 导出 / 删除 **挂在「我的」Info 页**，随本功能一起排期（行为细则仍以 16 Specify 为准）。  
**不做**：任务卡业务逻辑（10）、四角色对话逻辑（08/11）、付费页（12）。

## 前端

### AC-01-F01 主页必现信息
- **Given** 用户已有本地档案（03 完成后）或空档案  
- **When** 打开 App 进入主页  
- **Then** 首屏 **同时** 可见且可被测试定位（`Key`/`Semantics`）：
  1. 当前阶段文案：仅允许 `备孕` | `孕期` | `生产` | `产后` 四者之一（空档案显示 `备孕`）
  2. 周次：孕期显示 `孕X周`（X 为整数 ≥ 1）；产后显示 `产后第X周`；备孕显示 `备孕中`（无周数字）；生产显示 `待回填分娩日期` 或 `产褥第X周`（与 03 状态机一致）
  3. 四个角色入口：文案固定为 `小暖` `林医生` `苏心` `阿嬷`
  4. 「今日任务」区域：P1 无任务时显示固定文案 `今日任务将在后续版本提供`，**不得**假造已完成任务数

### AC-01-F02 角色入口行为（P1）
- **Given** 主页  
- **When** 点击 `小暖`  
- **Then** 进入会话页（04），会话 `type=SOLO`，`role=XIAONUAN`。  
- **When** 点击 `林医生` / `苏心` / `阿嬷`  
- **Then** P1：进入同一会话页但顶部展示固定条 `该角色将在后续版本开放`，**禁止**调用 LLM。P2：11 完成后改为真正 SOLO。

### AC-01-F03 底部导航
- **Given** 主页  
- **When** 查看底部栏  
- **Then** 恰好 3 项，标签固定：`首页` `对话` `我的`。  
  - `对话` → 会话列表（04）；无会话时列表为空态文案 `还没有对话`。  
  - `我的` → **Info 页**（本功能交付壳；不是 03 档案表单本身）。

### AC-01-F05 「我的」Info 页（挂载 16 P1）
- **Given** 点底栏 `我的`  
- **When** 进入 `/me`  
- **Then** 页面标题精确为 `我的`，且列表 **至少** 含下列三项（文案逐字、可测 `Key`）：
  1. `隐私说明`
  2. `导出我的数据`
  3. `删除本地数据`  
- 档案编辑（末次月经/预产期）由 03 另加一行 `编辑档案`；P1 在 03 未合并前 **可以没有** 这一行。  
- 隐私三项的点击行为由 **T16-01…03** 实现；01 只保证入口存在。未实现时点击不得 crash（可空操作或 SnackBar `即将提供`，该占位句若使用必须逐字一致）。

### AC-01-F04 无障碍与断网
- **Given** 飞行模式  
- **When** 打开主页  
- **Then** 主页 **完整可渲染**（不依赖 LLM）。不得全屏错误页。

## 后端 / 本地服务层

主页 **禁止** 直连 LLM。只读 03 暴露的 `UserProfileSnapshot`。

### AC-01-B01 快照契约
- **Given** 本地有/无用户  
- **When** 主页加载  
- **Then** 调用 `UserProfileRepository.getSnapshot()` 恰好 1 次（冷启动），返回结构见 Plan；失败时用默认快照 `{ stage: PREP, weekValue: null }`，并打本地日志，**不弹系统 crash**。

### AC-01-B02 无云同步
- **Given** P1  
- **When** 进入主页  
- **Then** 0 次业务 HTTP（LLM 健康检查也不在主页触发）。
