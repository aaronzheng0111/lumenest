# 用户验收步骤 · 00 开发与运行环境

对象：技术负责人（非必须会写 Dart）。

1. 打开 `sdd/00-dev-environment/fixtures/toolchain.json`，记下 Flutter 版本号。
2. 按仓库根 README 安装该版本（不要自作主张升到「更新的」）。
3. 复制 `env/dev.json.example` → `env/dev.json`，填入测试用 key（不要提交）。
4. 运行文档中的构建命令，确认生成 debug APK。
5. 打开 APK（或让开发用脚本扫描），确认无法在包内搜到你刚填的完整 key。
6. 用 Android 模拟器或真机安装 **dev** 包，确认能启动到占位首页（01 未完成前允许空白 Flutter 默认页）。
7. 若团队声明「使用 LLM 代理」：浏览器或 curl 访问 `/health`，必须看到 `status=ok`。若声明不用代理：本步跳过并签字 N/A。
