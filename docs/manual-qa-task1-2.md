# Task 1–2 手动验收清单（TASK-101～108 · TASK-201～205）

> **用途**：在真机 / 模拟器上逐项点选验收。  
> **隐私**：本清单仅使用模拟文案与 fixture。**禁止**填写真实末次月经、预产期、真实姓名、真实对话原文到截图外发；**禁止**把 API Key 写进本文件或聊天记录。  
> **自动化基线**：`cd app && flutter test` 应全绿（Phase 2 完成后）。

---

## 1. 前置条件

### 1.1 工具链

- Flutter 与 `sdd/00-dev-environment/fixtures/toolchain.json` 锁定版本一致（见仓库根 `README.md`）。
- Android SDK / 模拟器或真机可用；`flutter doctor` 无阻塞错误。

### 1.2 启动方式（dev flavor）

```bash
cd app
# 可选：复制本地密钥模板（勿提交）
cp -n env/dev.json.example env/dev.json

# 无 Key：可验证缺 key 文案「未配置模型服务」
flutter run --flavor dev

# 有出网 LLM（仅本机 dart-define，勿写入仓库）：
flutter run --flavor dev \
  --dart-define=LLM_BASE_URL=https://你的兼容端点 \
  --dart-define=LLM_API_KEY=你的密钥
```

### 1.3 环境说明

| 项 | 说明 |
|---|---|
| Flavor | `dev`（本清单默认） |
| LLM | P1 **非流式** `chat/completions`；超时约 15s，失败不重试 |
| 知识库 | 本地 fixture 子串检索，**不出网** |
| 群聊会诊 | 调试默认 `groupConsultEnabled=true`；关断时提示「需要升级订阅」 |
| 本地通知 08:00 | T10-04 可记 N/A（未接系统推送权限时首页任务仍可用） |

### 1.4 隐私同意

冷启动应看到隐私说明页。点「同意并继续」后再测对话发送；未同意发送应提示「请先在「我的」同意隐私说明」。

- **期望**：恰好三个 Tab；角色显示「小暖 / 林医生 / 苏心 / 阿嬷」。

- **步骤**：底栏「我的」→ 隐私说明 → 同意；导出；删除弹窗文案确认后关闭或执行。
- **期望**：隐私文案含本地存储说明；导出为占位 JSON（无密钥）；删除确认文案正确。

- **目的**：缺 key / 失败有固定文案。
- **步骤**：无 `--dart-define` 发一句日常；有 key 再发一句日常。
- **期望**：缺 key →「未配置模型服务」；失败 →「稍后再试」；成功 → 助手回复。

## 3. Phase 2 · TASK-201～205

### TASK-201 本地知识检索

- **目的**：fixture 语料子串检索；来源 Chip 最多 3 条。
- **步骤**：向小暖问「孕吐吃什么」「睡不着侧卧」；再问无关「量子力学」类话题。
- **期望**：相关问有「来源：」+ title；无关可无「来源」二字；不出现联网失败专属于检索的错误。
- **结果**：- [ ] 通过 / - [ ] 失败

### TASK-202 上下文切片与摘要

- **目的**：Prompt 含【档案】【习惯】【近期摘要】；成功回合写摘要；可清除。
- **步骤**：连续 2～3 轮日常对话（有 LLM key）→「我的」→「清除对话摘要」→ 确认文案「将删除本地摘要，对话气泡仍保留」。
- **期望**：清除后气泡仍在；再次对话仍可用（摘要空则【近期摘要】为无）。
- **结果**：- [ ] 通过 / - [ ] 失败

### TASK-203 四角色解锁

- **目的**：林医生 / 苏心 / 阿嬷 SOLO 可聊。
- **步骤**：首页分别点三角色 → 输入框可用 → 各发一句模拟日常。
- **期望**：无锁定横幅；气泡 speaker 名为对应角色；人设不自称「GPT」。
- **结果**：- [ ] 通过 / - [ ] 失败

### TASK-204 群聊会诊 / Handoff

- **目的**：群聊入口、路由、多 speaker 气泡。
- **步骤**：
  1. 「对话」Tab →「群聊会诊」。
  2. 发 `@林医生 产检相关模拟问题`。
  3. 发含喂养词的模拟句（如吐奶/喂奶类 fixture 语义）。
  4. （可选）将 `groupConsultEnabled` 关断后应见「需要升级订阅」。
- **期望**：同一会话多角色名可见；单轮 LLM ≤2；显式 @ 指向对应角色。
- **结果**：- [ ] 通过 / - [ ] 失败

### TASK-205 每日任务卡

- **目的**：首页「今日任务」按阶段生成；勾选持久化。
- **步骤**：备孕默认应见「喝水打卡」类模板 → 勾选 → 杀进程重开仍为 DONE → 再点回 PENDING。改档案到孕 16 周附近可出现散步类任务（见 `task_templates.json`）。
- **期望**：无任务时文案「今天没有安排的任务」；不出现药品剂量文案。
- **结果**：- [ ] 通过 / - [ ] 失败

## 4. 端到端路径

### 4.1 Happy path（陪伴闭环）

1. 同意隐私 → 首页确认阶段/任务。  
2. 点小暖 → 问孕吐相关模拟问题 → 见来源 Chip（若命中）→ 回复落库。  
3. 回首页勾选任务。  
4. 「对话」→ 群聊会诊 → `@苏心` 或情绪类模拟句 → 见对应 speaker。  
5. 「我的」清除摘要，气泡仍在。

- **结果**：- [ ] 通过 / - [ ] 失败

### 4.2 Red-flag safety path

1. 任意角色或群聊发送红旗模拟句。  
2. 确认本地拦截回复 +「安全提示」。  
3. 确认未出现模型闲聊式绕过（无剂量处方、无诊断口吻强化）。

- **结果**：- [ ] 通过 / - [ ] 失败

## 5. 已知限制

- LLM **非流式**（无逐字打字机效果）；加载态为「正在回复」。
- 知识检索为 **P1 假实现**（子串 / bigram），非向量库。
- 摘要为规则截断前 80 字，非二次 LLM 总结。
- 群聊订阅门禁用调试开关；正式权益墙在 Phase 3（TASK-302）。
- 本地 08:00 任务推送（T10-04）可 N/A。
- 自动化测试中首页任务列表常 override 为空，避免未初始化 DB 卡住；真机以本节手动项为准。
