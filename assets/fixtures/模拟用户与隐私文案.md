# 模拟用户与启动隐私文案

> 给测试 / 验收用的夹具。改 JSON 即可换用户或改启动页文案，**不必改 Dart**。  
> App 通过 `assets/fixtures/` 读取（`app/assets` 软链到仓库 `assets/`）。

## 文件

| 文件 | 用途 | 谁读 |
|---|---|---|
| [`mock-user.json`](./mock-user.json) | 模拟孕期用户档案 | 冷启动首页（`AssetMockUserProfileRepository`） |
| [`privacy-notice.json`](./privacy-notice.json) | **每次启动**弹出的隐私状况页 | `LaunchPrivacyNoticePage`、「我的 → 隐私说明」 |

## 当前模拟用户（林林）

见 `mock-user.json`：孕期第 **16** 周，预产期 `2026-12-20`，LMP `2026-03-15`。

`stage` 只允许：

| JSON 值 | 首页阶段 Chip | 周次文案 |
|---|---|---|
| `PREP` | 备孕 | 备孕中 |
| `PREGNANT` | 孕期 | 孕X周（`weekValue` ≥ 1） |
| `DELIVERY` | 生产 | 无 `weekValue` → 待回填分娩日期；有则 产褥第X周 |
| `POSTPARTUM` | 产后 | 产后第X周 |

改完 JSON 后 **热重启（R）**，不要只 hot reload。

## 启动隐私页（每次冷启动）

`privacy-notice.json` 字段：

- `title` / `statusLabel` / `statusDetail` / `body` / `bullets[]`
- `primaryAction`：关闭本页进入 App（「知道了」）
- `agreeAction`：写入 `privacyAccepted=true` 并进入 App（「同意并继续」）

正文需继续包含子串 **`健康数据以设备本地为主`** 与 **`不上传整库`**（sdd/16），改文案时请保留。

## 自动化测试

Widget 测试默认 `showLaunchNotice: false`，并用内存 `FakeUserProfileRepository`（空档案 = 备孕），不依赖本夹具。
